# Data Science Tasks

Assignments and practical work from my **Introduction to Machine Learning** course
at Kazakh-British Technical University (KBTU), Fall 2026.

## Contents

| Folder | Topic |
|--------|-------|
| assignment1 – assignment7 | Graded assignments (e.g. assignment4: linear and KNN regression on life satisfaction vs GDP) |
| p_6, p_7 | Practicals: vector operations, ... |
| p4_iris | Iris dataset classification |
| pr_probability | Probability exercises |
| pr2, pr3, pr5 | Practical sessions |
| risk | ... |

## Tech stack

- Python 3
- NumPy, pandas, Matplotlib
- scikit-learn
- Jupyter Notebook

## How to run

1. Clone the repo
   `git clone https://github.com/aknuraru/data_science_tasks.git`
2. Install dependencies
   `pip install numpy pandas matplotlib scikit-learn jupyter`
3. Open any folder and run the `.ipynb` notebook
   `jupyter notebook`
